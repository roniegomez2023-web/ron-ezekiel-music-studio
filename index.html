Settings & Data

Workspace data

Records are stored in this browser using localStorage. They do not sync across devices and may disappear if you clear browser data. Export backups regularly.

YouTube API roadmap

Read-only YouTube Data API and Analytics API access uses Google OAuth in your browser. Access tokens are kept in memory, not in localStorage. Never paste API secrets or refresh tokens into public GitHub code.
